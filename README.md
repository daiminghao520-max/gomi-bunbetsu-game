# 日中韓ごみ分別ゲーム

给小学生（4 年级左右）玩的网页游戏。孩子们分别用日本、中国上海、韩国首尔三地的规则给垃圾分类，答完一题马上看到「なぜ？」的解说，还能看到别的国家把同一样东西分到哪里，最后在「まとめ」里对比「国家主导型（中韩）」和「自治体裁量型（日本）」。

（日本語の説明は いちばん下に あります。）

---

## 怎么打开

1. 把整个文件夹放在一起（`index.html`、`style.css`、`game.js`、`data.js` 缺一不可）。
2. **双击 `index.html`**，用 Chrome / Edge / Safari / Firefox 打开就能玩。
3. 不需要联网，也不需要安装任何东西。
   - 联网时标题等文字用 Google Fonts 的「Zen Maru Gothic」（圆体）。
   - 没网时自动换成电脑自带的字体（Windows 一般是 BIZ UDPゴシック / Meiryo），照样能玩。
4. 发表时可以直接跳到某一关：在地址栏 `index.html` 后面加
   - `#jp`（日本）、`#sh`（上海）、`#kr`（首尔）、`#summary`（まとめ）

**手机 / 平板上玩**：在手机上直接打开本地 HTML 文件比较麻烦。比较省事的办法有两种：发表时用电脑接投影仪；或者把文件夹上传到网页空间（例如 GitHub Pages），用平板打开网址。注意上传以后谁都能看到。

## 玩法

- 顶部按钮：`おと`（声音开 / 关）、`ふりがな`（注音开 / 关）、`？`（玩法说明）。
- 每个国家随机出 **8 题**。每个垃圾桶至少会当一次正确答案，「必出题」也一定会出（见下文 `mustInclude`）。
- 作答方式：
  - 把垃圾卡片**拖**到垃圾桶上（鼠标、手指、触控笔都可以，用的是 Pointer Events）；
  - 或者直接**点**垃圾桶；
  - 电脑上也可以按键盘 `1`〜`4`。
- 布局：竖屏手机上垃圾桶排成 2×2，横屏和宽屏排成 1×4。
- 日本关卡在介绍页、游戏画面上方和结果页都会提示「市町村によって ルールが ちがう」。结果页还有一张「ほかの まちでは どうかな？」的对比卡。
- 三个国家都玩完后会出现「まとめ」，里面有对比表和思考题。「国を えらぶ」页面上的「まとめを 見る」按钮随时都能点。
- 星星成绩存在浏览器里（localStorage）。想清空的话，删除浏览器的网站数据，或者用无痕窗口打开。
- 系统设置里打开「减少动态效果」（prefers-reduced-motion）后，卡片飞入、彩纸、晃动这些动画都会停掉。
- 弹窗都是游戏自己画的，没有用 alert / confirm。

## 文件结构

| 文件 | 内容 |
|---|---|
| `index.html` | 页面骨架 |
| `style.css` | 外观（2×2 / 1×4 布局、动画、减少动画设置） |
| `game.js` | 游戏逻辑（拖拽、计分、弹窗、各画面） |
| `data.js` | **所有数据**：国家、垃圾桶、垃圾题目、解说文字、图（SVG） |
| `README.md` | 本说明 |

一般只需要改 `data.js`，`game.js` 不用动。

## 怎么加新垃圾

用记事本或 VS Code 打开 `data.js`。

### 第 1 步：在 `items: [ ... ]` 里加一条

```js
{
  id: 'cardboard',                 // 英文 id，不能和别的重复
  name: 'だんボール',               // 卡片上显示的名字（日文）
  icon: 'cardboard',               // 用哪张图（见第 2 步）
  answers: { jp: 'shigen', sh: 'recyclable', kr: 'recycle' },
  why: {                           // 「なぜ？」解说（可以不写）
    jp: 'たたんで、ひもで しばって 出すよ。',
    sh: '紙は たいらに して 出すよ。'
  }
},
```

- `answers`：写「国家 id: 垃圾桶 id」。
  - 不想在某个国家出这道题，就不写那个国家。
  - 写 `'varies'` 的话，这个国家不出这道题，但在别国的「ほかの 国では？」里会显示「まちによって ちがう」（日本的电池就是这样写的）。
- `why`：不写的话，会显示垃圾桶自带的说明。
- `notes`（可选）：例如 `notes: { jp: 'まちに よっては「もえるごみ」の ところも あるよ！' }`，会显示成黄色提醒。
- 难的汉字写成 `{漢字|かんじ}` 就会带注音，例如 `{牛乳|ぎゅうにゅう}パック`。
- 中文或韩文原文写成 `[zh]湿垃圾[/zh]`、`[ko]일반쓰레기[/ko]`，会换成对应的字体。

**垃圾桶 id 一览**

| 国家 id | 垃圾桶 id → 名字 |
|---|---|
| `jp` 日本 | `moeru` もえるごみ ／ `moenai` もえないごみ ／ `pura` プラスチック ／ `shigen` 資源ごみ |
| `sh` 上海 | `recyclable` 可回收物 ／ `hazardous` 有害垃圾 ／ `wet` 湿垃圾 ／ `dry` 干垃圾 |
| `kr` 首尔 | `general` 일반쓰레기 ／ `food` 음식물 쓰레기 ／ `recycle` 재활용품 ／ `special` 전용 수거함 |

### 第 2 步：图

- **用现成的图**：`icon` 填 `data.js` 里 `icons: { ... }` 已有的名字（`banana`、`egg`、`pet`、`can`、`newspaper`、`battery` 等，全部在文件最下面）。
- **画新图**：在 `icons` 里加一条，内容是 SVG 图形，画布是 100×100。黑色描边由游戏自动加，你只要写形状和颜色：

```js
cardboard:
  '<rect x="16" y="30" width="68" height="50" rx="4" fill="#d9a066"/>' +
  '<path d="M16 46 H84" fill="none"/>',
```

- 找不到图时会显示一个「?」，游戏不会坏。

### 第 3 步：确认

双击 `index.html` 玩一下。如果新垃圾没出现或者出错，按 `F12` → `Console`，会看到类似下面的日文提示：

- `[data.js] ごみ箱の id が ちがいます: …`（垃圾桶 id 写错了）
- `[data.js] 絵が ありません: …`（图的名字写错了）

另外注意：每一条后面的逗号 `,` 不能漏，引号要成对。

### 其他可以改的地方（都在 `data.js`）

| 想改什么 | 改哪里 |
|---|---|
| 每个国家出几题 | 文件开头的 `questionsPerStage: 8` |
| 某个国家一定要出的题 | 该国的 `mustInclude: ['egg', 'toy']` |
| 介绍页 / 提示 / 结果页的文字 | 该国的 `intro`、`notice`、`playNotice`、`points`、`cityDiff`、`think` |
| まとめ对比表里放哪些垃圾 | `summary.compareItems` |
| まとめ的思考题 | `summary.think` |

  https://www.city.kumamoto.jp/kiji00372785/index.html

### 游戏里做了简化的地方（发表时可以说明）

- **日本关卡**是「あるまち（某个镇）」的通用例子，不对应具体哪个市。实际上分类、叫法（燃えるごみ / 可燃ごみ / 燃やすごみ）、收集日都因市町村而异。这一点正好就是小组主题。
- **首尔的「リサイクル」桶**：实际要再细分成纸、纸盒、罐、瓶、塑料、塑料袋（비닐）、透明 PET 瓶等。游戏里合成了一个桶，介绍页有说明。
- **首尔的「専用ボックス」**：电池、荧光灯、药各有各的回收箱（药一般投放在药店、保健所），不是家门口的一个桶，游戏里合成了一个。
- 规则会更新，发表前建议对照上面的资料再确认一遍。

## 日本語の かんたんな 説明

**ひらきかた**：フォルダの 中の `index.html` を ダブルクリック。インターネットは いりません（つながっている ときだけ Google Fonts を 使います）。`index.html#jp` / `#sh` / `#kr` / `#summary` で その画面から はじめられます。

**ごみの 足しかた**：`data.js` の `items` に 1つ 書き足します。

```js
{ id: 'cardboard', name: 'だんボール', icon: 'newspaper',
  answers: { jp: 'shigen', sh: 'recyclable', kr: 'recycle' },
  why: { jp: 'たたんで、ひもで しばって 出すよ。' } },
```

- `answers` は「国の id: ごみ箱の id」（上の 表を 見てね）。その国で 出さない ときは 書かない。
- 絵は `icons` に ある 名前を 使うか、100×100 の SVG を 足します。
- うまく いかない ときは `F12` → Console に「[data.js] …」と 出ます。
